# Dungeon Escape – COMP3016 CW2 Coursework


## Build Instructions
- Open the solution file: DungeonEscape.sln
- Set configuration to x64 / Debug
- Build and Run

## Controls
- A / D : Change lane
- W     : Jump
- S     : Crouch
- ESC   : Quit
